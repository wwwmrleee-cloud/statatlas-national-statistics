StatAtlas — national statistics for 24 countries and 9 indicators, 216 figures in all, every one fetched from the World Bank's World Development Indicators and labelled with its source and year. Ranked, sortable tables; top-10 charts for every indicator; a profile page for each country with its rank on all nine indicators; and a compare view that puts up to three countries side by side on every indicator. Works on desktop and on a phone, with no network requests — the whole site is static files.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
